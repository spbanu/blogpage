## Requirements

- JWT bearer authentication against a configurable OpenID Connect authority.
- Fallback policy requiring authentication on all endpoints.
- Rate limiting, secure headers and `ProblemDetails` error responses.
- OpenTelemetry traces and metrics out of the box.

## Research

Compared the ASP.NET Core defaults against the OWASP API Security Top 10 to decide which protections belong in a template and which are service-specific.

## Architecture Options

| Option | Notes |
|---|---|
| `dotnet new` template | Easy to adopt, drifts after creation |
| Shared NuGet package of defaults | Updates flow to services, adds coupling |
| Both | Template for structure, package for security defaults |

## Architecture Decision

Leaning towards **both** — decision record in progress.
