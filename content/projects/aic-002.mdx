## Requirements

- Seeded defects across categories: null handling, concurrency, authorization, resource leaks, injection.
- Deterministic scoring rules that don't depend on a second model's judgement where avoidable.
- Results stored per run so trends can be charted.

## Research

Reviewed existing approaches to evaluating LLM output: exact-match scoring, rubric-based human grading and model-graded evaluation. Model-graded evaluation is fast but needs spot-checking against human labels.

## Architecture Options

| Option | Notes |
|---|---|
| Manual spreadsheet | Fine for 10 cases, unmanageable at 100 |
| Console app + JSON results | Simple, versionable, CI-friendly |
| Hosted eval platform | Powerful, but another system to operate |

## Architecture Decision

**Decision:** a .NET console application that reads the corpus, calls the reviewer, and writes JSON results that CI publishes as an artifact.

## Implementation

```csharp
public sealed record SeededDefect(string File, int Line, string Category, string Description);

public sealed record ReviewScore(int TruePositives, int FalsePositives, int Missed)
{
    public double Precision => TruePositives / (double)Math.Max(1, TruePositives + FalsePositives);
    public double Recall => TruePositives / (double)Math.Max(1, TruePositives + Missed);
}
```

## Testing

The matcher and scorer have their own unit tests — an evaluation harness with bugs produces confident nonsense.

## AI Evaluation

Metrics per run: precision, recall, and findings by category. Results are compared against the previous run and the best run.

## Security Review

The corpus contains only synthetic code — no proprietary source is sent to external models.

## Performance

Runs are batched and cached by (prompt, model, case) so unchanged combinations aren't re-evaluated.

## Lessons Learned

<Statement type="lesson">
Precision matters as much as recall. A reviewer that flags everything is ignored within a week.
</Statement>

## Future Improvements

- Add real (anonymised) historical bugs to the corpus.
- Track cost per useful finding.
